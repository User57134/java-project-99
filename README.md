#  Менеджер задач

Веб-приложение для управления задачами с архитектурой на базе REST API. Система позволяет ставить задачи, назначать исполнителей, изменять статусы, добавлять метки и применять фильтрацию.

Для работы в системе требуется авторизация, доступ к ресурсам разграничивается в зависимости от ролей пользователей.

🎯 **Демо-версия приложения:** [Task Manager Live](https://java-project-99-rsap.onrender.com)

## ✨ Ключевые возможности

### 📋 Управление задачами
* **Полный цикл CRUD:** создание, просмотр, редактирование и удаление задач.
* **Исполнители:** назначение ответственных за выполнение из списка пользователей.
* **Жизненный цикл:** гибкое изменение статусов задач и прикрепление меток (тегов).
* **Поиск и фильтрация:** фильтрация общего пула задач по различным пересекающимся параметрам.

### 👤 Пользователи и Безопасность
* **Управление аккаунтами:** добавление, удаление и просмотр профилей пользователей.
* **JWT-аутентификация:** безопасный доступ к REST API с помощью токенов.
* **Авторизация:** разграничение прав доступа (редактировать/удалять сущности могут только их авторы или администраторы).

### 🛠 Стабильность системы
* **Обработка ошибок:** централизованное отслеживание ошибок.

## 🛠 Запуск и развертывание

### Требования
* **Java 21** (или выше)
* **Gradle** (используется встроенный wrapper `./gradlew`)

### Пошаговый запуск локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/User57134/java-project-99.git
   cd java-project-99
   
   ```

2. **Соберите проект:**
   ```bash
   make setup
   ```

3. **Запустите приложение:**
   ```bash
   make start
   ```

После этого приложение станет доступно локально по адресу: `http://localhost:8080`
